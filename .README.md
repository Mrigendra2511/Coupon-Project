# Coupon API (TypeScript + Express + MongoDB)

A robust REST API for managing discount coupons and calculating order discounts. Built with TypeScript, Express, and Mongoose adhering to production-level standards (`asyncHandler`, `ApiError`, `ApiResponse`).

## Tech Stack
- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Express.js
- **Database:** MongoDB (Mongoose)
